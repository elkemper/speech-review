# Speech Review

Локальное приложение для разбора записей вебинаров: распознаёт речь, находит филлеры, паузы, обрывы, повторы и растяжки, даёт быстрый переход к нужному месту по клику на слово.

MVP рассчитан на macOS + Apple Silicon. Обработка полностью локальная: запись и транскрипт не покидают компьютер. Интернет нужен только для однократной загрузки модели.

**English version:** [`README.md`](README.md)

## Что умеет

- Транскрипция через **CrisperWhisper 2.0** и нативный рантайм **audio.cpp** с Metal.
- Нарезка длинной записи по паузам; первый фрагмент короче, поэтому первые слова появляются раньше.
- Промежуточный транскрипт сохраняется после каждого фрагмента и сразу доступен для разбора.
- Осциллограмма с зумом, панорамой, маркерами дефектов, цветными подложками помеченных слов и выделением слов.
- Контраст осциллограммы (только отображение) поднимает тихую речь над шумом, поэтому речь и настоящая тишина хорошо различимы; настраивается в параметрах.
- Клик по слову или маркеру — переход к этому месту в видео.
- Очередь дефектов: фильтры, подтверждение/удаление, заметки, ручные метки.
- Соседние ручные метки объединяются в одну логическую метку: её можно подтвердить за раз, разъединить обратно или удалить целиком.
- У выбранного дефекта или метки заливка показывает исходный участок, а ручки задают итоговый вырез; при захвате соседних меток ручкой они объединяются.
- Отмена и повтор действий (`⌘Z` / `⇧⌘Z`) с журналом истории; изменения правил дефектов и отступов пропуска откатываются вместе с пересчитанным списком и интервалами.
- Панель дефектов можно растягивать за границу и полностью скрывать; высота окна просмотра и таймлайна тоже настраивается перетаскиванием.
- У выбранной метки в правой панели есть мини-осциллограмма с контекстом ±3 с (настраивается), подвижными ручками выреза, масштабом 1–4× с горизонтальной прокруткой, бледными соседними метками, цветными подложками слов и общим бегунком.
- Выделение слов кликом, `Shift`+кликом или перетаскиванием; метка ставится точно по границам выделения.
- Выделенные слова можно подтвердить (`Shift+Enter`) или удалить (`Shift+R`), если в них есть дефекты.
- Закладки: `B` запоминает место, к закладке можно вернуться из списка и продолжить с последней.
- Пороги дефектов задаются ползунком и полем ввода; для каждого типа настраивается минимальная длительность, а соседние дефекты можно автоматически объединять в группу.
- Слово с коротким дефектом ниже порога открывает временную карточку «кандидат». Измените вырез, подтвердите, удалите или добавьте заметку, чтобы оставить его настоящим дефектом.
- Отступы при пропуске настраиваются отдельно для каждого типа и для группы; в паузе можно оставить настраиваемое количество тишины, чтобы рез не звучал обрубленно. Ручки на таймлайне задают итоговый вырез, а заливка остаётся исходным дефектом. Двойной клик по ручке возвращает рассчитанный вырез.
- Цикл по фрагменту, скорость 0.5–2×, горячие клавиши.
- Скип-режим: при проигрывании вырезаются все дефекты и ручные метки, кроме удалённых, с настраиваемыми отступами. Подтверждённый дефект сохраняет вырез, который был на момент подтверждения, поэтому последующие правки отступов его не сдвигают.
- Удалённые дефекты остаются тонкой карточкой с кнопкой возврата, если включено «Показывать удалённые дефекты». Подтверждённая карточка сворачивается в компактную строку с кнопкой отмены; у неподтверждённой слева есть кнопки удаления и подтверждения.
- Экспорт дефектов в CSV (Excel) и JSON; набор полей CSV и разделитель настраиваются. Базовые колонки CSV — границы итогового выреза, а границы исходного дефекта можно добавить отдельными полями. В JSON также есть объединённый список `cuts` для монтажа.
- Экспорт чистого видео по текущим меткам: разрешение, три пресета качества, программные H.264/HEVC или аппаратные VideoToolbox-энкодеры. Прогресс можно отменить; исходный файл не изменяется.
- Интерфейс на русском и английском: язык выбирается в **Настройки → Общие → Интерфейс** и применяется к панелям, меню, системным диалогам, прогрессу и ошибкам. При первой установке берётся системный язык, если это русский или английский. Значения в CSV всегда на английском, независимо от языка интерфейса.
- Тёмная тема в духе Photoshop, автосохранение проекта после каждого действия.

## Требования

- macOS 13+ на Apple Silicon (M1/M2/M3/M4/M5).
- Node.js 20+ и npm для сборки.
- ~3 ГБ свободного места: движок ~100 МБ, ffmpeg ~80 МБ, модель ~1.6 ГБ.
- 8 ГБ RAM и больше.

## Быстрый старт

```bash
npm install
npm run fetch:engine
npm run dev
```

`npm run fetch:engine` скачивает в `resources/`:

- `engine/` — `audiocpp_cli` из audio.cpp v0.9.4 (macOS arm64 Metal);
- `ffmpeg/ffmpeg` — статический ffmpeg 6.1.1.

Затем в приложении:

1. Откройте **Настройки** → **Общие** → **Скачать модель** (Q8_0, ~1.6 ГБ). Там же можно удалить скачанную модель.
2. Нажмите **Открыть запись** и выберите MP4/MOV/MKV/MP3/WAV.
3. Запустите **Распознать**. Готовые фрагменты появляются в транскрипте по мере обработки.
4. Разбирайте дефекты справа: подтверждайте реальные и удаляйте ложные, затем экспортируйте CSV/JSON или чистое видео кнопкой **Экспорт видео…**.

Модель скачивается с Hugging Face и проверяется по SHA-256. Повторно скачивать её не нужно.

## Сборка DMG

```bash
npm run package:mac
```

Скрипт проверит платформу (`npm run check:platform`), наличие движка и ffmpeg (`npm run check:resources`), соберёт приложение и положит DMG в `dist/`.

Проверка логики без запуска Electron:

```bash
npm test
npm run typecheck
```

Сборка подписывается ad-hoc (`codesign --sign -`), но не нотаризуется. Если macOS блокирует первый запуск:

```bash
xattr -cr "/Applications/Speech Review.app"
open "/Applications/Speech Review.app"
```

Либо нажмите на приложение правой кнопкой → **Открыть** → **Открыть**.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Space` | играть / пауза |
| `←` / `→` | −2 / +2 секунды |
| `Shift` + `←` / `→` | −10 / +10 секунд |
| `[` / `]` | предыдущий / следующий дефект |
| `K` | включить / выключить режим пропуска |
| `Enter` | подтвердить активный дефект |
| `R` | удалить активный дефект |
| `Shift+Enter` | подтвердить все дефекты в выделении |
| `Shift+R` | удалить все дефекты в выделении |
| `M` | добавить ручную метку: по выделенным словам или в текущей позиции |
| `B` | поставить закладку в текущей позиции |
| `L` | включить / выключить цикл по активному дефекту |
| `F` | следовать за играющим словом |
| `1`–`6` | скорость 0.5, 0.75, 1, 1.25, 1.5, 2× |
| `Home` / `End` | в начало / в конец |
| `Cmd+O` | открыть запись |

В режиме пропуска хоткеи подтверждения, удаления и ручной метки работают только на паузе.
| `Cmd+,` | настройки |
| `Cmd+Z` / `Ctrl+Z` | отменить действие |
| `Shift+Cmd+Z` / `Ctrl+Y` | повторить действие |
| `Esc` | снять цикл / выделение |

Клик по осциллограмме перематывает, клик по маркеру дефекта или его зоне выреза — выбирает дефект. Клик по слову в транскрипте перематывает на его начало.

Выделение слов в транскрипте: обычный клик выбирает слово, `Shift`+клик расширяет диапазон, перетаскивание мышью выделяет несколько слов. Метка `M` использует точные границы выделения. На таймлайне `Shift`+драг выделяет точный диапазон времени, а `M` создаёт ручную метку с этими границами. `Ctrl`/`Cmd`+колесо меняет масштаб, обычная прокрутка панорамирует; кнопки `+`, `−` и `⤢` дублируют это мышью.

Если выбрать дефект в списке или транскрипте, на таймлайне появятся две вертикальные ручки выреза — их можно перетаскивать мышью. Заливка за ними — исходный найденный или выделенный участок: отступы видны как штриховка цветом типа дефекта снаружи, а оставленная тишина — как нейтральная штриховка чуть более светлым оттенком подложки внутри. Если ручка ручной метки дотягивается до соседней, метки объединяются в логическую; кнопка «разъединить» в панели возвращает отдельные метки. Двойной клик по ручке сбрасывает ручной вырез и возвращает рассчитанные отступы. Ширину панели дефектов меняют перетаскиванием её левой границы, скрывают кнопкой `⟩`, возвращают кнопкой «Дефекты» в шапке. Высоту окна просмотра и таймлайна меняют перетаскиванием горизонтальных разделителей; транскрипт занимает оставшееся место.

В настройках на вкладке «Дефекты» каждый тип дефекта — это одна строка: чекбокс включения, минимальная длительность, отступы до/после и настройки этого типа (пауза — последняя строка; её минимальная длительность и есть порог тишины, там же оставляемая тишина и правило про конец предложения). У автообъединения свой чекбокс и максимальная пауза; при выключении значение паузы сохраняется. Режим пропуска и то, что пропускать, включаются в плеере (кнопка ⏭), а не в настройках.

## Правила дефектов по умолчанию

| Тип | Условие | Важность |
|---|---|---|
| `filler` | `[UH]`, `[UM]`, `[ER]`, `[HM]` от CrisperWhisper | высокая |
| `filler` | слова «э», «эм», «ну», «вот», «типа», «короче», «как бы» и т.п. | низкая |
| `pause` | разрыв между словами ≥ 1.2 с (минимальная длительность) | средняя |
| `repetition` | одинаковое слово в пределах 2 с | средняя |
| `elongation` | 3+ одинаковые буквы подряд | средняя |
| `false_start` | слово длиной > 2 заканчивается на `-` | средняя |
| `vocal_sound` | прочие события `[laughter]`, `[cough]` и т.п. | низкая |
| `unclear` | низкий confidence | **выключено** |

Пауза после `.`, `?`, `!` или `…` по умолчанию не считается дефектом: это нормальная межфразовая остановка. Порог, окно повторов и лексические филлеры настраиваются в приложении без пересборки и без повторного распознавания.

## Как это устроено

```
React renderer
   │  window.api (preload, contextBridge)
   ▼
Electron main
   ├─ ffmpeg: извлечение 16 кГц mono WAV, silencedetect
   ├─ нарезка WAV по середине пауз; первый фрагмент до 3 мин, остальные — по настройке
   ├─ audiocpp_cli --family crisperwhisper --backend metal
   ├─ слияние words.json всех фрагментов → transcript.json
   ├─ осциллограмма peaks.json
   └─ проект: project.json + transcript.json + peaks.json
```

- Видео отдаётся в renderer через привилегированную схему `app-media://` с поддержкой HTTP Range. Отдельный HTTP-сервер не поднимается.
- Движок запускается отдельным процессом на каждый фрагмент. Модель перезагружается между фрагментами — это осознанный компромисс для простоты MVP.
- `words.json` от audio.cpp содержит `start_sample`/`end_sample` при 16 кГц. Парсер терпим к trailing comma.
- Дефекты вычисляются в renderer из транскрипта и правил. Списки подтверждённых и удалённых ID, архив удалённых меток и заметки хранятся в `project.json`.
- Промежуточный транскрипт пишется с `transcriptComplete: false`; при первом частичном результате подтверждения и удаления сбрасываются, потому что транскрипт пересобран и старые совпадения могли измениться. Ручные метки сохраняются.
- Скип-режим не перекодирует видео: во время проигрывания позиция перескакивает через итоговые вырезы. Отступы «до/после» настраиваются отдельно для каждого типа дефекта и для группы, а в паузах остаётся настраиваемое количество тишины, чтобы рез не звучал обрубленно. Перетащенная ручка сохраняет явный вырез и побеждает отступы; двойной клик возвращает рассчитанный вырез. Подтверждение фиксирует вырез на текущих отступах, поэтому последующие их правки его не сдвигают.

## Где лежат данные

```
~/Library/Application Support/Speech Review/
├── settings.json
├── models/CrisperWhisper2.0-GGUF/
├── projects/<uuid>/
│   ├── project.json
│   ├── transcript.json
│   └── peaks.json
└── tmp/jobs/
```

Удаление проекта в приложении удаляет его папку. Видеофайл не копируется и не изменяется.

## Диагностика

**«Движок audio.cpp не найден» / «ffmpeg не найден»**

```bash
npm run fetch:engine
```

Затем перезапустите приложение. В настройках есть кнопка «проверить» и пути к бинарникам.

**Модель не проходит проверку SHA-256**

Удалите недокачанный файл в `~/Library/Application Support/Speech Review/models/CrisperWhisper2.0-GGUF/` и скачайте заново. Загрузка поддерживает докачивание после обрыва.

**Видео не воспроизводится**

Chromium не поддерживает часть кодеков (например, некоторые MKV/HEVC). Распознавание при этом работает, потому что аудио извлекает ffmpeg. Для просмотра перекодируйте запись в MP4/H.264:

```bash
ffmpeg -i input.mkv -c:v libx264 -c:a aac -movflags +faststart output.mp4
```

**Долго**

Ориентир для M4 Pro: 10 минут аудио ≈ 1.5 минуты распознавания (RTF ≈ 0.15). На M5 Air может быть немного медленнее. Для ускорения можно выбрать модель Q4_K в настройках — качество будет ниже.

**Приложение заблокировано macOS**

См. раздел про ad-hoc подпись выше.

## Ограничения MVP

- Только Apple Silicon и macOS. Windows/Linux-сборки не проверялись.
- Нет word-level confidence: audio.cpp пишет `confidence: 0`, поэтому тип `unclear` отключён. См. `docs/BACKLOG.md`.
- Нет диаризации и разделения по спикерам.
- Один активный проект в окне; фоновые задачи не ставятся в очередь.
- При аварийном завершении приложения незавершённая транскрипция начинается заново. Завершённые проекты сохраняются.
- Модель распространяется по некоммерческой исследовательской лицензии.
