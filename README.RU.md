# Speech Review

Локальное приложение для macOS для разбора записей вебинаров. Распознаёт речь прямо на компьютере, находит филлеры, паузы, обрывы, повторы и растяжки и позволяет перейти к любому моменту по клику на слово. Подтвердите реальные дефекты, удалите ложные — и экспортируйте чистое видео или список вырезов.

Обработка полностью локальная: запись и транскрипт не покидают компьютер. Интернет нужен только для однократной загрузки модели.

**English version:** [`README.md`](README.md)

## Скачать и установить

Готовый DMG опубликован в разделе **Releases** на странице проекта на GitHub: откройте последний релиз и скачайте DMG для Apple Silicon.

Требования: macOS 13 или новее на Apple Silicon, около 3 ГБ свободного места на диске и 8 ГБ RAM.

1. Откройте DMG и перетащите **Speech Review** в **Applications**.
2. При первом запуске macOS может заблокировать приложение: сборка подписана ad-hoc, но не нотаризована. Нажмите на приложение правой кнопкой → **Открыть** → **Открыть** или один раз выполните:
   ```bash
   xattr -cr "/Applications/Speech Review.app"
   ```
3. В **Настройки → Общие** нажмите **Скачать модель** (Q8_0, ~1.6 ГБ). Это делается один раз; файл проверяется по SHA-256.

## Как пользоваться

1. Нажмите **Открыть запись** и выберите файл MP4, MOV, MKV, MP3 или WAV.
2. Нажмите **Распознать**. Готовые фрагменты появляются в транскрипте, пока остальные ещё обрабатываются.
3. Разберите дефекты справа: подтвердите реальные, удалите ложные, добавьте заметки или ручные метки.
4. Клик по слову или маркеру перематывает к нужному месту. Включите режим пропуска, чтобы слушать без дефектов.
5. Экспортируйте CSV/JSON или чистое видео кнопкой **Экспорт видео…**.

## Что умеет

- Распознавание на устройстве через CrisperWhisper 2.0 и рантайм audio.cpp с Metal; длинная запись режется по паузам, а промежуточный транскрипт доступен по мере готовности фрагментов.
- Осциллограмма с зумом, панорамой, маркерами дефектов, цветными подложками слов и выделением; клик по слову или маркеру перематывает.
- Автоматический поиск филлеров, пауз, обрывов, повторов, растяжек и вокализаций с настраиваемыми порогами и автообъединением соседних дефектов.
- Очередь дефектов с фильтрами, подтверждением, удалением, заметками и ручными метками; соседние метки объединяются в одну логическую, которую можно подтвердить, разъединить или удалить целиком.
- Редактируемые границы выреза: заливка показывает найденный участок, ручки задают итоговый вырез, а отступы по типам и настраиваемая тишина в паузе не дают резу звучать обрубленно.
- Режим пропуска при проигрывании вырезает все дефекты и ручные метки, кроме удалённых; подтверждённый дефект сохраняет вырез, который был на момент подтверждения.
- Отмена и повтор действий с журналом истории, автосохранение после каждого действия, закладки, цикл и скорость 0.5–2×.
- Экспорт CSV/JSON с настраиваемыми полями и разделителем; экспорт чистого видео с выбором разрешения, пресетов качества, программных или аппаратных VideoToolbox-энкодеров и необязательным кроссфейдом звука и видео на каждом стыке, с прогрессом и отменой.
- **Таблица дефектов** в отдельном окне в духе Excel: вид экспортируемого CSV с растягиваемыми столбцами, выделением и массовым удалением строк, добавлением строки с точным временем и заметкой, правкой времени и заметки прямо в ячейках, копированием заметок, undo/redo, синхронизацией кликов с основным окном и переключателем светлой темы для окна таблицы.
- Интерфейс на русском и английском, только тёмная тема.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Space` | играть / пауза |
| `←` / `→` | −2 / +2 секунды |
| `Shift` + `←` / `→` | −10 / +10 секунд |
| `[` / `]` | предыдущий / следующий дефект |
| `K` | включить / выключить режим пропуска |
| `Enter` | подтвердить активный дефект |
| `R` | удалить активный дефект |
| `Shift+Enter` | подтвердить все дефекты в выделении |
| `Shift+R` | удалить все дефекты в выделении |
| `M` | добавить ручную метку: по выделенным словам или в текущей позиции |
| `B` | поставить закладку в текущей позиции |
| `L` | включить / выключить цикл по активному дефекту |
| `F` | следовать за играющим словом |
| `1`–`6` | скорость 0.5, 0.75, 1, 1.25, 1.5, 2× |
| `Home` / `End` | в начало / в конец |
| `Cmd+O` | открыть запись |
| `Cmd+,` | настройки |
| `Cmd+Z` / `Ctrl+Z` | отменить действие |
| `Shift+Cmd+Z` / `Ctrl+Y` | повторить действие |
| `Esc` | снять цикл / выделение |

В режиме пропуска хоткеи подтверждения, удаления и ручной метки работают только на паузе.

## Работа с таймлайном и транскриптом

- Клик по осциллограмме перематывает, клик по маркеру дефекта или его зоне выреза выбирает дефект. Клик по слову в транскрипте перематывает на его начало.
- Выделение слов в транскрипте: обычный клик выбирает слово, `Shift`+клик расширяет диапазон, перетаскивание выделяет несколько слов. Метка `M` использует точные границы выделения. На таймлайне `Shift`+драг выделяет точный диапазон времени, а `M` создаёт ручную метку с этими границами.
- У выбранного дефекта появляются две ручки выреза на таймлайне и мини-осциллограмма с контекстом ±3 с в правой панели. Заливка за ручками — исходный найденный или выделенный участок: отступы видны как штриховка цветом типа дефекта снаружи, а оставленная тишина — как более светлая нейтральная штриховка внутри.
- Если дотянуть ручку ручной метки до соседней, метки объединяются в логическую; кнопка **разъединить** в панели возвращает отдельные метки. Двойной клик по ручке сбрасывает ручной вырез и возвращает рассчитанные отступы.
- Ширину панели дефектов меняют перетаскиванием её левой границы, `⟩` скрывает панель, кнопка **Дефекты** в шапке возвращает её. Горизонтальные разделители меняют высоту окна просмотра и таймлайна.
- `Ctrl`/`Cmd`+колесо меняет масштаб, обычная прокрутка панорамирует; кнопки `+`, `−` и `⤢` делают то же мышью.
- На вкладке **Дефекты** в настройках каждый тип — это одна строка: чекбокс включения, минимальная длительность, отступы до/после и настройки этого типа. Пауза — последняя строка; её минимальная длительность и есть порог тишины, там же оставляемая тишина и правило про конец предложения. У автообъединения свой чекбокс и максимальная пауза. Сам режим пропуска включается в плеере (⏭), а не в настройках.

## Правила дефектов по умолчанию

| Тип | Условие | Важность |
|---|---|---|
| `filler` | `[UH]`, `[UM]`, `[ER]`, `[HM]` от CrisperWhisper | высокая |
| `filler` | слова «э», «эм», «ну», «вот», «типа», «короче», «как бы» и т.п. | низкая |
| `pause` | разрыв между словами ≥ 1.2 с (минимальная длительность) | средняя |
| `repetition` | одинаковое слово в пределах 2 с | средняя |
| `elongation` | 3+ одинаковые буквы подряд | средняя |
| `false_start` | слово длиной > 2 заканчивается на `-` | средняя |
| `vocal_sound` | прочие события `[laughter]`, `[cough]` и т.п. | низкая |
| `unclear` | низкий confidence | **выключено** |

Пауза после `.`, `?`, `!` или `…` по умолчанию не считается дефектом: это нормальная межфразовая остановка. Порог, окно повторов и лексические филлеры настраиваются в приложении без пересборки и без повторного распознавания.

## Диагностика

**Приложение заблокировано macOS**

Нажмите на приложение правой кнопкой → **Открыть** → **Открыть** или один раз выполните `xattr -cr "/Applications/Speech Review.app"`, как описано в разделе [Скачать и установить](#скачать-и-установить).

**Сообщение, что движок или ffmpeg не найден**

Оба файла входят в DMG. Переустановите приложение из последнего релиза. Если вы запускаете проект из исходников, выполните `npm run fetch:engine` и перезапустите приложение.

**Видео не воспроизводится**

Chromium не поддерживает часть кодеков (например, некоторые MKV/HEVC). Распознавание при этом работает, потому что аудио извлекает ffmpeg. Для просмотра перекодируйте запись в MP4/H.264:

```bash
ffmpeg -i input.mkv -c:v libx264 -c:a aac -movflags +faststart output.mp4
```

**Модель не проходит проверку SHA-256**

Удалите недокачанный файл в `~/Library/Application Support/Speech Review/models/CrisperWhisper2.0-GGUF/` и скачайте заново. Загрузка поддерживает докачивание после обрыва.

**Долго**

Ориентир для M4 Pro: 10 минут аудио ≈ 1.5 минуты распознавания (RTF ≈ 0.15). Более лёгкая модель Q4_K работает быстрее, но менее точно; выбрать её можно в настройках.

## Ограничения

- Только macOS на Apple Silicon; сборки для Windows и Linux не проверялись.
- Пока нет word-level confidence, поэтому тип `unclear` отключён.
- Нет диаризации и разделения по спикерам.
- Один активный проект в окне; фоновые задачи не ставятся в очередь.
- При аварийном завершении приложения незавершённая транскрипция начинается заново. Завершённые проекты сохраняются.
- Модель распространяется по некоммерческой исследовательской лицензии.

## Данные и приватность

Обработка полностью локальная. Проекты и настройки лежат в `~/Library/Application Support/Speech Review/`; удаление проекта в приложении удаляет его папку. Исходный видеофайл не копируется и не изменяется. Структура папок описана в [`docs/DATA_MODEL.md`](docs/DATA_MODEL.md).

## Сборка из исходников

На Mac:

```bash
npm install
npm run fetch:engine
npm run dev
```

`npm run package:mac` собирает DMG в `dist/`. Проверить логику без запуска Electron можно через `npm test` и `npm run typecheck`.
